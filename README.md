# Destino Cordillera - Equipo 04
Solemne Práctica de Desarrollo en Aplicaciones Web
## Nombre del Proyecto
Destino Cordillera (Plataforma Promotora de Turismo y Viajes).
## Integrantes del Equipo
* Patricio Chaug
* David Bravo
* Guillermo Tolentino
## Descripción del Sitio
Sitio web de promoción turística para la comuna de Destino Cordillera. Su objetivo es difundir los principales atractivos, actividades al aire libre, opciones de hospedaje, restaurantes y un formulario de reservas y contacto.
## Instrucciones para Ejecutar el Sitio
1. Descargar o clonar el repositorio desde GitHub.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html` en el navegador web (o utilizando la extensión Live Server).
## Tecnologías Utilizadas
* HTML5 (Estructura semántica)
* CSS3 (Estilos propios y diseño responsivo)
* Bootstrap 5.3 (Utilizado en páginas generales; con `panoramas.html` como página de CSS propio exclusivo)
