# Equipo_04-Desarrollo-app-Web
Solemne Practica de Desarrollo en Aplicaciones Web
#Nombre del proyecto
Destino Perfecto (Experiencia Promotora de Viajes a Destino Cordillera
#Integrantes del Equipo
Patricio Chaug, David Bravo y Guillermo Tolentino
#Descripción del Sitio
Es un promotor de viajes en Destino Cordillera, su finalidad es buscar los mejores lugares y actividades.
#Instrucciones para Ejecutar el Sitio
1.Descargar el Repositorio desde github.
2.Abrir la carpeta dentro de VSCODE.
3.Utilizar extensión de preferencia o Docker para abrir un LocalHost.
#Tecnologías Utilizadas
HTML5, CSS3 y BootStraps.
#Distribución de responsabilidades de cada integrante
Patricio Chaug: Pruebas Unitarias + Página de Alojamiento.
Guillermo Tolentino: Página Senderismo + Index.
David Bravo: Creación de Reserva + Index y Pruebas Unitarias.
